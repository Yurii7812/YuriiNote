## 2. 決まったこと

### 2.1 構成
1. **盤面のエンジンは 1 つだけ作り、タロットアプリ・トピックインデックスの地図・ふつうのブレストが共有する。** デッキ（引く道具）は盤面とは分けて、あとから足せる部品にする。
2. **ブレストは「専用のノート」にする（案 B）。** ふつうのノートと同じ ID・題・バックリンクを持つ .md。開くと盤面が画面いっぱいに出る。
   - ファイル: 盤面の JSON（```board、v2）＋ ノードの文字を木の形で自動で書き出した文章（アプリなしで読める・検索に引っかかる）。
   - 小さな盤面を、他のノートの中に埋め込めること（今の ```board のまま）も残す。同じ形式を使う。
   - 「このノードをノートにする」: ブレストの途中で、良いノードを 1 つ選ぶとノートが作られ（ノードの文字が題）、ノードには `->ID` が付く。**最初から入れるか後回しかは未決（4 を参照）。**
3. **形式 v2（ノートの中の ```board）**: `t` = ノード（今の `[x,y,文字]` に、種類を任意で足す: 文字／カード／キーワード）、`l` = ノード同士の線（今のペン線 `s` とは別）。v1 は、そのまま読めて、保存時に v2 へ移す。ノードの文字は、今と同じくノートの本文として数える（検索・(n)・バックリンクが効く）。
4. **トピックインデックスの地図は、独立したノート**（利用者が確定）。名前は 1-0、1-1、1-1-2、1-2a のようにハイフン入り。地図の中で `(n)` を使え、番号は地図ごとに数える。
   - **「地図の地図」（トピックインデックスのトピックインデックス）は `n-all`**（利用者が確定）。区画 n の地図の題をキーワードにし、番号（1-1 など）を横に付け、関係のある地図同士を線で結ぶ、手書きの地図。ほかの地図と同じ決まり（題を上に・ノードはキーワード＋ID・線はキーワード同士だけ・埋まったら `1-all-2`・(n) は地図ごと）。区画をまたぐいちばん上のものは `0-all`。区画 0 を別の役には使わない（「0」は今のまま区画の一覧の仮のページ）。
   - 実装: ID の検査に「数字のあとに `all`」を許す。一覧では **先頭**（1-all、1-0、1-1…）。地図を作ったら、画面側が「1-1 認識論」のような候補をその地図の地図に置けると楽（線は手で引く。自動では引かない）。
   - 紙の運用: 1-0 に新しい語を書いていき、増えたら 1-1 など新しい番号の地図に移す。1-0 には任意で「→1-1」と書く（これは「続き」ではなく「移した先」。続きは `1-0-2`）。区画 1 の中に「1」という番号のノートは作らない（1-1 が「1 の続き」に読めてしまうため）。
   - **番号の決まり（v1.5.1 で実装済み）**: 索引・地図の番号は、区画の番号だけで作る（1-1、5-3、1-all など）。ノートの ID（1a-1 など）では作らない。ノートから作っても、そのノートの区画の番号になる（1a から作れば 1-1）。新しい作成の入口（ブレストのノート・地図）を足すときも守る。すでに 1a-1 のような番号で作られた索引が vault にあるかもしれない。自動では変えていない。見つけたら利用者に聞く。
   - 地図の決まりは `docs` 外の利用者のノート（vault の `1a11b`「トピックインデックスの書き方」）と、相談の整理にあった: 地図の単位はトピック／ノードはキーワード（ID は横に付記）／線はキーワード同士だけ／ノートを書いたらそのキーワードを足す（すでにある語なら ID を足すだけ）／雑の地図 n-0、話題の地図 n-1…、続き n-n-2、掘り下げ n-1a、全体図は新しい番号／地図同士は同じ語を両方に書いて結ぶ（矢印なし）。
5. **タロットのカード画像は、アプリに同梱し、ノートにはカード名（と正逆）だけを書く。** vault に画像を入れない。
6. **APK にはブレスト・地図を入れない。**
7. **左のパネルは、折りたためるようにする。**

### 2.2 ブレストの作り方（利用者の指摘と方針）
- いまのタロットアプリは「ブレストが使いづらい」。具体的に:
  - 右クリックで動かせない。
  - 並べたタロット（スプレッド）を **ポンと一度に出せない**。今は 1 枚ずつ、ブレストの途中でしか出せない。
- 目指す形:
  - **何もない盤面から、ふつうにブレストを始められる**。そこへ、タロットを **必要なときにポンと出せる**。1 枚なら 1 枚、ヘキサグラムならヘキサグラムを、まとめて置く（置く位置の意味つき）。
  - ブレストのやり方は、YuriiNote のボードに合わせて **もっとシンプルな UI** にする（機能は削がない。見せ方を整理する）。操作の基本は、いまの YuriiNote ボードと同じ: クリックで文字／ドラッグでペン／Ctrl+ドラッグで動かす／右クリックメニュー。tarot-brainstorm の「ノードから別へドラッグでつなぐ・Enter 次・Tab 広げる」を足す。**右クリックでの移動に対応**する。
- 「引く」は盤面のメニューから 1 回で。デッキ・引き方・乱数の元の設定は、盤面の外に畳む。

### 2.3 移動と UI（YuriiNote 全体）
- **ブレスト → ブレスト（他のノートも）を、同じ画面のまま移れる**: 枠（タブ・一覧）は動かさず、中身だけが入れ替わる。履歴で戻れる。戻ったとき、画面ごとの状態を復元する（ブレストは拡大率と位置、ふつうのノートはスクロールとカーソル。いまは「開くたびに一番上になる」ことがある）。
- ノードにカーソルを合わせて Space で、移動せずにのぞく小さなカード → Enter で入る。
- 入る・出るは、軽く短いアニメーションで位置が分かるようにする（利用者への提案は「おすすめ」で出してある。**最終確認は未**）。
- 画面の上に「今いる場所」（A → B → ノート 3a）を出し、途中へも飛べる。
- **YuriiNote 全体の UI を洗練する。いまは粗い。機能は削がずに。**
  - 書いている間は枠・ボタンを薄くする（静かな枠）。
  - 上の行を、ノート・ブレスト・日記で揃える（題・戻る・進む・今いる場所）。
  - 集中表示（左の一覧と右のパネルを 1 キーでたたむ）。
  - Ctrl+U の画面を「探して開く」にも広げる。
  - 余白・文字の大きさ・色・アイコンの揃え方を整理する。
